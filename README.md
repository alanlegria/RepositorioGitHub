Descripción
Se analizan diez compuestos halogenados con información de CAS SciFinder: 100 reacciones en las que son reactivo y 100 en las que se obtienen. El flujo de trabajo es: Excel → Google Colab → informe en LaTeX → presentación en Power BI → repositorio en GitHub.
Estructura del repositorio
Carpeta	Contenido	Enlace
`Datos/`	Tablas de sustancias, reacciones y obtenciones	halogenados.xlsx
`Análisis Visual/`	Notebook de Colab y presentación en Power BI	Colab · Power BI
`Documentación/`	Informe en LaTeX (código fuente, bibliografía, imágenes y PDF)	Informe (PDF) · main.tex · references.bib
Cómo usar los archivos
Análisis gráfico: abre el notebook con el botón de Colab de arriba y ejecuta Entorno de ejecución → Ejecutar todas.
Presentación: descarga el archivo `.pbix` y ábrelo con Power BI Desktop.
Informe: lee el PDF directamente o compila `main.tex` (necesita la carpeta `imagenes/` y `references.bib`).
